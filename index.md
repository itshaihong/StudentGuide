# Welcome to StudentGuide
StudentGuide brings together learning modules and practical reference guides for students at STAR.

## Learning modules

The first two modules are being planned for students who have used STM32 and are new to Git or Zynq.
Their outlines describe the learning goals; interactive lessons are still to be built.

- [Git workflow]({{ '/modules/git/' | relative_url }}): understand where changes live and review the scope of a commit.
- [From STM32 to Zynq 7000]({{ '/modules/zynq-7000/' | relative_url }}): follow a change from source files to the program or hardware running on a board.

## Reference guides

Use the [reference guides]({{ '/guides/' | relative_url }}) for reComputer setup, coding standards and Git conventions, and Satcat.

Post your questions, findings, and feedback in the [repository discussions](https://github.com/itshaihong/StudentGuide/discussions).
