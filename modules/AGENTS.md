# Learning content

Follow root `AGENTS.md`, `PROJECT_MEMORY.md`, and `docs/v2/product-rules.md`.
Use `_data/curriculum.json` for module identity, order, prerequisites, and lesson mapping.
Do not duplicate that catalog in templates or browser code.

Each module needs one adult engineering use case, a clear starting point, acceptance
criteria, connected chapters, and a teammate-ready outcome. Teach prerequisites first.
Introduce jargon through contextual definitions, not unexplained abbreviations.
Preserve all old pilot and reference routes. Keep learner-facing content English.
