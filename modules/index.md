# Learning modules

Two learning paths are being planned for students with some STM32 experience.
Both ask the same questions: what did I change, which files does it produce, who uses
those files next, and how do I check the result?

The pages below are module outlines. Interactive lessons are not yet available.

- [Git workflow]({{ '/modules/git/' | relative_url }}): inspect changes, choose a commit's scope, and understand local and remote state.
- [From STM32 to Zynq 7000]({{ '/modules/zynq-7000/' | relative_url }}): connect familiar embedded software concepts to hardware handoff and board execution.
